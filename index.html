Conceptual Foundations & Academic Reference Hub

First-Come, First-Served (FCFS)

The simplest disk scheduling algorithm. The I/O request queue is serviced strictly in the order of request arrival (FIFO).

THM = ∑i=1N |Ci - Ci-1|
  • ✔ Completely fair; zero starvation.
  • ✔ Extremely simple O(N) implementation.
  • ✖ High average seek distance; wild arm oscillations.

Shortest Seek Time First (SSTF)

Greedily selects the pending request that is closest to the current head position, minimizing immediate mechanical seek travel.

Next = argminc ∈ Q |c - Chead|
  • ✔ Substantially reduces total head movement.
  • ✔ High throughput for localized requests.
  • ✖ Starvation risk for tracks far from current cluster.

SCAN (Elevator Algorithm)

The disk arm sweeps continuously across the platter in one direction, servicing requests until reaching the boundary cylinder, then reverses.

THM = (Max - Head) + (Max - Minleft)
  • ✔ Eliminates starvation through uniform sweeps.
  • ✔ Excellent balance between throughput and fairness.
  • ✖ Reaches disk boundary even if no requests are there.
